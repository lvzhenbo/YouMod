# YouMod

## 《游戏自主吟》

> 金帛购得戏中游，何以教吾作楚囚？
>
> 修改随心添逸趣，逍遥本是我所求。
>
> 无端设限两时短，未付银钱便逐流。
>
> 吾戏吾心吾自主，岂由旁者定沉浮。

## 概述

YouMod 者，Wand 会员之解锁器也。夫 Wand 者，西洋之游戏修改器也，名曰 WeMod，以会员之限，拘寻常用户。非付金帛，不得享 Pro 之权；每用二时，辄遭驱逐。此诚霸王之条，岂君子所当为？

故吾辈铸此利器，以 Rust 重写，辅以 GUI 之界面，令操作一目了然，不假命令行之繁琐。一键可破其桎梏，复我游戏之自由。

## 界面

启之，则见一小窗，名曰「YouMod — 解 Wand 会员之锢」。窗分四域，井然有序：

**一曰：状态栏。** 顶置 YouMod 之名，右书「解 Wand 会员之锢」以明其志。其下示 Wand 安装之所在，绿点书「● 已破」以示功成，灰点书「○ 未破」以示待命。若未检得 Wand 之迹，则以赤字告之。

**二曰：补丁选项。** 列二勾选框，任君择之。其一曰「启 Pro 之权」，启之则破会员之限，尽享 Pro 之特权；其二曰「绝更新之路」，启之则绝其更新之路，免遭日后修复之忧。默认勾选 Pro，而更新则留待君意。

**三曰：操作按钮。** 左设「施补丁」之主钮，色取青蓝，以彰其要；中设「复旧观」之次钮，边框勾勒，以示其慎；右设「删旧版」之钮，其色赤，旁标旧版本数，以警其险。条件不备，则钮灰不可按。既打补丁，亦可一键还原，如时光倒流，完好如初，绝无后患。若有旧版残留，一键尽删，唯留最新，省磁盘之空间，去累赘之烦扰。

**四曰：日志区。** 窗之下半，专辟一栏，以等宽字体录诸操作之详。绿字示成功，赤字示失败，灰字示信息。步步留痕，一目了然，虽新手亦无所惑。

## 用法

1. 启动 YouMod，自动检 Wand 之所在，兼查旧版本之有无。
2. 勾选所需选项：启 Pro 之权、绝更新之路。
3. 击「施补丁」，稍候片刻，日志区绿字告成。
4. 若欲复旧观，但击「复旧观」即可，原版之 app.asar 早已备份，无损复原。
5. 若有旧版本残留，击「删旧版」一键清理，唯留最新，日志区逐一列明所删。
6. 若不慎关闭，下次启动自动查知已破之态，绿点醒之。

## 释名

何以名 YouMod？You 者，汝也，亦谐「由」之音；Mod 者，修改也。合而观之——「由你做主，修改随心」，此正《游戏自主吟》之志也。
